✨ Features
🔐 Secure Authentication: JWT-based login/signup for Admin & Teachers
📊 Interactive Dashboard: Real-time attendance stats (Present/Absent/Total)
📝 Bulk Attendance Marking: Mark attendance for an entire class/section in one click
🔍 Advanced Filtering: Search & filter by date, class, section, or student
📄 Report Generation: Export attendance records as CSV
👥 Role-Based Access: Admins manage students & reports; Teachers mark & view attendance
📱 Fully Responsive: Mobile-friendly UI built with Tailwind CSS
⚡ API-Driven Architecture: RESTful endpoints with proper error handling & validation
A modern, full-stack web application for efficiently managing student attendance. Designed for schools and educational institutions, it provides role-based access, bulk attendance marking, real-time dashboards, filtering, and CSV report generation.
